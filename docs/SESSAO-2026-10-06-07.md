#### 3. Barra de rolagem + habilidade prepara os dados
- Layout em painel: `.rt-layout` > `.rt-main` + `.rt-panel` (blocos Vida / Dados /
  Rolagens) — `champion-sheet.hbs` + css.
- Clicar numa **habilidade** (linha da aba Poderes):
  - define `_lastAbilityId` (sempre a última clicada);
  - `_prepareAbilityRoll` (`character-sheet.js:333`) acha até **2 traços nomeados no

  - dropdowns tingidos `.rt-primed`, botão combinado brilha `.rt-ready`.
- **Nenhum card ao clicar** — o texto da habilidade sai **junto com a rolagem**

  Lease de **20s** (`ABILITY_CARD_LEASE_MS`, `_armAbilityLease`, renovado a cada

- Rolagem bloqueada com slot vazio: aviso `NeedsTrait` ("Escolha Poder + Qualidade
  antes de rolar") — em `make-roll` e nos botões de slot único.
- Qualquer rolagem do painel limpa `.rt-ready`/`.rt-primed` (`character-sheet.js:442`).

#### 4. Popup de notificação de chat em 20s
- `runeterra.js` (hook `init`): `foundry.applications.sidebar.tabs.ChatLog.NOTIFY_DURATION = 20000`.
- Mecânica: os cards flutuantes de notificação são do **core** (aparecem quando a aba
  de chat não está ativa na sidebar e a janela tem ≥ ~1024px CSS). O ticker lê a
  constante a cada tick → mutação em runtime basta; **hover pausa** a contagem.
  5s (padrão) → **20s**. Confirmado pelo Fabio no cliente dele.
- Com a aba de Chat ativa não há card flutuante (só o pip na aba) — **é o
  comportamento correto, não "consertar"**.
- Não confundir com **Dice So Nice** (dados 3D): persistência dele é a opção
  "Milissegundos Antes de Esconder" nas configurações do módulo, por usuário.

   Trocar os dropdowns de Poder/Qualidade → persistem.
3. **Import-only**: crie um Campeão vazio → ficha abre no estado de importação
   (`.rt-import-pending`); "Importar personagem Runeterra" → JSON da Forja → ficha
   preenche. Re-importar JSON atualizado → abilities antigas substituídas.
   JSON inválido → erro e nada é alterado.
   JSON de teste: exporte no site da Forja (Arquivo → Exportar campeão); o parser
   exige estado `v: 1` e nome em `info.name`/`info.alias` (`parseChampion`,

   como "—", tintura dourada, botão combinado aceso. Rolar → card com o texto da
   habilidade **acima dos dados**; brilho/tintura limpam. Rolar com slot vazio →
   aviso "Escolha Poder + Qualidade antes de rolar". Rolar de novo <20s → o card da
